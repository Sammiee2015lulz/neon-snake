# Neon Snake 🐍

A fun, neon-styled Snake game built with pure HTML, CSS, and vanilla JavaScript.

## Features
- Neon glow effects and color-shifting snake
- Score tracking with local high score
- Smooth controls (Arrow keys or WASD)
- Responsive and self-contained (single HTML file)
- Game over screen with restart

## How to Play
1. Open `index.html` in any modern browser
2. Use **Arrow Keys** or **WASD** to move
3. Eat the glowing pink food to grow and score points
4. Avoid walls and your own tail!
5. High score is saved in your browser

## Run Locally
Just double-click `index.html` or serve it with any static server.
